# estudio-midia

Hospedagem temporária (GitHub Pages) das fotos que o Estúdio envia para o TikTok
pela Content Posting API (`PULL_FROM_URL` exige um endereço verificado).

- `m/<lote>/slide-NN.jpg`: fotos de um envio; o Estúdio apaga a pasta depois que a TikTok confirma.
- O arquivo de verificação da TikTok (URL prefix) fica na raiz.
